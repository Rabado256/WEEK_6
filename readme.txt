# Week 6: React Task Manager

A modular, reactive Task Management application built with React.js and Vite, demonstrating component composition, props, state hooks (`useState`, `useEffect`), list rendering, and local storage persistence.

---

##  Features
1. **Component-Based Architecture:** Divided into clean, reusable components (`Header`, `TaskForm`, `TaskList`, `TaskItem`).
2. **State & Props:** Manages application data via React state and passes data down via props.
3. **Persistence:** Automatically syncs task state with browser `localStorage` using `useEffect`.
4. **Filtering System:** Switch seamlessly between **All**, **Active**, and **Completed** views.
5. **Responsive Design:** Optimized layout scaling fluidly across mobile and desktop viewports.
